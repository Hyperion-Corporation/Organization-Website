Organization site: static export on GitHub Pages

Date: 2026-07-01
Categories: Infrastructure, Web

The Hyperion organization website is a fully static Next.js export deployed to GitHub Pages from the Organization-Website repository.

Why static

  • No server runtime or API routes to operate
  • basePath /Organization-Website matches project Pages hosting
  • Interactive demos can still ship as client islands where useful

Stack

Next.js (App Router, output: 'export'), React, TypeScript, Tailwind CSS, Vitest, and Cypress—plus optional docs tooling under docs/website.
